# Наставник — сервис карьерных консультаций

Полнофункциональный MVP сайта-визитки для бизнеса карьерных консультаций.

## 🚀 Технологии

- **Next.js 14** с TypeScript и App Router
- **Tailwind CSS** для стилизации
- **Plausible Analytics** для аналитики
- **Google Tag Manager** для детальных метрик
- **Адаптивный дизайн** для всех устройств

## 📁 Структура проекта

```
src/
├── app/
│   ├── cases/page.tsx          # Страница с историями успеха
│   ├── contact/page.tsx        # Страница контактов с формой
│   ├── pricing/page.tsx        # Страница с тарифами
│   ├── services/page.tsx       # Страница услуг с пагинацией
│   ├── layout.tsx              # Основной layout с навигацией
│   └── page.tsx                # Главная страница
├── components/
│   └── Navigation.tsx          # Компонент навигации
└── globals.css                 # Глобальные стили
```

## 🛠 Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите проект в режиме разработки:
```bash
npm run dev
```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## 🚀 Развертывание на Netlify

1. Соберите проект:
```bash
npm run build
```

2. Загрузите папку `.next` на Netlify или подключите репозиторий

3. Настройте переменные окружения (если нужно):
   - `NEXT_PUBLIC_PLAUSIBLE_DOMAIN` - домен для Plausible Analytics
   - `NEXT_PUBLIC_GTM_ID` - ID для Google Tag Manager

## 📊 Аналитика

Проект настроен для работы с:
- **Plausible Analytics** - основная аналитика
- **Google Tag Manager** - детальные метрики и события

События, которые отслеживаются:
- `click_cta` - клики по кнопкам CTA
- `submit_form` - отправка форм
- `view_service` - просмотр услуг
- `view_pricing` - просмотр тарифов

## 🔧 Настройка

Для настройки аналитики обновите:
1. Домен в Plausible Analytics скрипте
2. GTM ID в layout.tsx
3. Email для формы обратной связи в contact/page.tsx
